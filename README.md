
# E-commerce Sales Analysis Using Python

## Project Overview
This project analyzes e-commerce sales data to identify sales trends and generate useful business insights.

## Objectives
- Analyze monthly and yearly sales.
- Identify the highest- and lowest-performing months.
- Compare sales across product categories.
- Analyze sales and profit by customer segment.

## Tools and Technologies
- Python
- Pandas
- Plotly
- Jupyter Notebook

## Key Findings
- Highest sales month: January
- Lowest sales month: December

## Project Workflow
1. Load and inspect the dataset.
2. Clean and prepare the data.
3. Perform exploratory data analysis.
4. Group sales data and compare performance.
5. Create visualizations and summarize findings.

## How to Run
1. Download the notebook.
2. Open it in Jupyter Notebook.
3. Install the required libraries if needed.
4. Run the notebook cells in order.

## Conclusion
The analysis helps identify sales patterns and supports data-driven business decisions.
